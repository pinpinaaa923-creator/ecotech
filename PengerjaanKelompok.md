# Pengerjaan Kelompok — EcoTech

## Project

**Nama Project:** EcoTech — Technology for a Greener Future

**Tema:** Teknologi Ramah Lingkungan dan Edukasi Digital

EcoTech merupakan website edukasi digital yang membahas dampak perkembangan teknologi terhadap lingkungan serta mendorong penggunaan teknologi secara lebih bertanggung jawab dan berkelanjutan.

## Alur Kolaborasi

Project dikembangkan secara kolaboratif menggunakan Git dan GitHub.

Setiap anggota mengerjakan bagian masing-masing dan melakukan commit terhadap perubahan yang telah dibuat.

Perubahan kemudian diunggah ke repository GitHub untuk diintegrasikan dan diperiksa bersama.

### Tools yang Digunakan

- Visual Studio Code
- Git
- GitHub
- Tailwind CSS
- Live Server

## Hasil Akhir

Seluruh bagian project akan diintegrasikan menjadi satu website EcoTech yang memiliki tampilan konsisten, responsive, informatif, dan sesuai dengan konsep teknologi ramah lingkungan.
